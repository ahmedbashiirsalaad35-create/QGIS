# Galgaduud Regional GIS Mapping Project

## Project Overview

The **Galgaduud Regional GIS Mapping Project** is a Geographic Information System (GIS) project developed using QGIS to organize, visualize, and analyze spatial data across the Galgaduud Region of Somalia.

The project brings together important geographic datasets related to administrative boundaries, transportation networks, healthcare facilities, and water resources. It provides a spatial overview of regional infrastructure and natural resources to support geographic analysis, resource management, and regional development planning.

## Project Objectives

- Map the administrative boundaries of Galgaduud Region.
- Visualize district boundaries and administrative divisions.
- Map and analyze regional road networks.
- Identify and visualize healthcare facility locations.
- Represent and analyze available water resource data.
- Support spatial planning and GIS-based decision-making.

## Data Layers

The project contains five main GIS layers:

### 1. Galgaduud Region
Represents the geographical boundary of Galgaduud Region.

### 2. Galgaduud Districts
Contains district-level administrative boundary information within the region.

### 3. Galgaduud Roads
Represents the road network and transportation infrastructure across the region.

### 4. Galgaduud Health
Contains spatial information about healthcare facilities and their geographic distribution.

### 5. Galgaduud Water Resources
Represents available spatial data related to water resources within the region.

## Software and Technologies

- **QGIS:** GIS project development, spatial data visualization, and mapping.
- **Coordinate Reference System:** WGS 84 (EPSG:4326).
- **Data Format:** Shapefile (SHP).

## Potential Applications

This project can support:

- Regional infrastructure planning.
- Road network analysis.
- Healthcare accessibility assessment.
- Water resource mapping and management.
- Administrative and territorial mapping.
- Geographic research and spatial decision-making.
